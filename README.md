# Axios API Practice Projects

This repository contains two beginner-friendly JavaScript projects demonstrating how to use Axios to fetch data from external APIs and display it on a webpage.

## Projects

### 1. Random Cat Facts
- Fetches random cat facts using an API.
- Displays the returned facts on the webpage.
- Demonstrates HTTP requests and DOM manipulation using JavaScript.

### 2. Random Dog Image
- Fetches dog image URLs from an API.
- Displays dog images dynamically on the webpage.
- Demonstrates API integration and DOM manipulation.

## Technologies Used
- HTML
- JavaScript
- Axios
- REST APIs

## How to Run
1. Clone or download this repository.
2. Open the `random-cat-facts` or `random-dog-image` folder.
3. Open the corresponding HTML file in your browser.
4. Click the button to fetch a cat fact or dog image.

## Learning Outcomes
- Making API requests with Axios.
- Working with asynchronous JavaScript.
- Handling API responses.
- Updating webpage content dynamically.
